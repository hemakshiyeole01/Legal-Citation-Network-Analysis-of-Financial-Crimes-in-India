# Legal Citation Network Analysis of Financial Crimes in India

This project focuses on analyzing **legal citation networks in Indian financial crime cases** using Supreme Court and other relevant judicial judgments.

The aim is to identify relationships between cases, understand citation patterns, and explore how important judgments influence subsequent decisions.

The project is currently under development. The complete methodology, dataset description, ontology, preprocessing pipeline, network construction, analysis, and results will be added as the project progresses.
